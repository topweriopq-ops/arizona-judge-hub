# Arizona Judge Hub — Servers

Здесь хранятся материалы и ссылки на законодательство серверов Arizona RP.

Для каждого сервера будет создана отдельная папка.

## Структура

* `servers/phoenix/` — законы сервера Phoenix
* `servers/tucson/` — законы сервера Tucson
* `servers/scottsdale/` — законы сервера Scottsdale
* `servers/prescott/` — законы сервера Prescott
